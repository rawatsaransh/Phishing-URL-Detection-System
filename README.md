# 🛡️ Phishing URL Detection System

A Python-based phishing URL detection and analysis tool that identifies suspicious indicators in URLs and generates a detailed security risk assessment report.

This project analyzes multiple security factors including URL structure, SSL certificates, DNS information, WHOIS domain intelligence, and VirusTotal reputation data to evaluate whether a URL may be associated with phishing activities.

---

# 🚀 Features

## 🔍 URL Feature Analysis

- URL parsing and validation
- HTTPS usage detection
- Long URL detection
- `@` symbol detection
- Multiple subdomain detection
- IP address detection inside URLs

---

## 🔐 SSL Certificate Analysis

- SSL certificate validation
- Certificate issuer information
- Certificate expiry details
- SSL error handling

---

## 🌐 DNS Analysis

- DNS resolution checking
- IP address extraction
- DNS failure detection

---

## 📅 Domain Intelligence

- WHOIS availability check
- Domain age analysis
- Domain expiry information
- WHOIS error handling

---

## 🛡️ Threat Reputation Analysis

- VirusTotal API integration
- Malicious engine detection
- Suspicious engine detection
- Harmless engine count retrieval

---

## 📊 Risk Assessment

- Weighted risk scoring system
- Multiple security indicators combined
- LOW / MEDIUM / HIGH risk classification
- Detailed terminal security report
